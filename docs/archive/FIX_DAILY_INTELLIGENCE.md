# Daily Intelligence Not Showing - Root Cause & Fix

## Problem Identified

The Daily Intelligence component on the dashboard is not visible because:

1. **No data in database**: The `/api/intelligence/daily` endpoint returns `{"summary":null}`
2. **Component behavior**: The `DailyIntelligence` component correctly hides itself when there's no data
3. **Data source**: Daily Intelligence is generated by the `decision_engine.generate_daily_summary()` function during pipeline execution

## Root Cause

The Daily Intelligence data is generated during the pipeline run in the "summary" stage. Looking at `backend/main_pipeline.py`:

```python
# Stage: Daily Summary
log.info("stage=summary msg=begin")
try:
    summary_text = decision_engine.generate_daily_summary()
    log.info("stage=summary output=%s", summary_text)
except Exception as exc:
    # ...
```

The `generate_daily_summary()` function:
1. Queries for top 3 articles with `state='decided'` 
2. Orders by `priority_score` descending
3. Generates content angles using LLM
4. Saves to `daily_intelligence` table

**The issue**: Either:
- The pipeline hasn't run yet, OR
- Articles aren't reaching the `'decided'` state, OR
- The decision engine stage is failing silently

## Quick Fix Options

### Option 1: Run the Pipeline (Recommended)
Trigger a full pipeline run to generate fresh Daily Intelligence:

```bash
# Via API
curl -X POST http://localhost:5000/api/pipeline/run

# Or via frontend
# Click "Fetch Data" button in the dashboard header
```

**Expected time**: 20-30 minutes for full pipeline

### Option 2: Manual Daily Intelligence Generation
Run just the decision engine stage:

```bash
# Inside Docker container
docker exec -it ai-pulse-backend bash
python -c "from backend.processors.decision_engine import decision_engine; print(decision_engine.generate_daily_summary())"
```

### Option 3: Check Pipeline Logs
Verify if the pipeline is running and check for errors:

```bash
# Check Docker logs
docker logs ai-pulse-backend --tail 100

# Look for:
# - "stage=summary msg=begin"
# - "stage=summary output=..."
# - Any errors in the decision engine
```
